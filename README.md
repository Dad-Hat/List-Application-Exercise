# APPLICATION
This app was developed for the fetch hiring team. 

## What it does
This application grabs data from the supplied url that contains a JSON array and displays that data organized to the user. 
That data is parsed, by their listId and their name. Organized into groups according to their listId and then sorted by their names. The data is also filtered to remove any items with a null or blank name.
